# FAQ с редактируемыми блоками

Для FAQ используй BlockListWidgetType, существующий шаблон блоков и `setup.json`, а не зашитый массив ответов. У шаблона `system-faq-2` поля `question` и `answer`; пример системного FAQ может относиться к multilink. Для обычной страницы отдельно выбери её page_kinds и размещение. Категория и block_template_handle — независимые ссылки: не выводи существование категории `faq` из названия секции. Если каталога нет, сохраняй подтверждённый handle из предоставленного пакета и отмечай ограничение; не выдумывай новый.

## Разметка и переключение

Простой вариант — нативные `details/summary`: браузер обслуживает клавиатуру и сообщает раскрытие без собственных ARIA-ID. Вариант с кнопкой также допустим: заголовок содержит button type=button, `aria-expanded` соответствует скрытию ответа, `aria-controls` ссылается на уникальный panel id, при необходимости `aria-labelledby` связывает панель с кнопкой.

Кнопка сама создаёт click при Enter/Space. Обработчик click плюс собственный toggle из keydown может выполнить действие дважды. Не требуй от синтетического keydown в DOM-тесте имитировать нативную активацию: проверь настоящий Enter/Space в браузере. Обработчик принадлежит только контролу вопроса; ссылка внутри ответа не переключает вопрос.

`widget_id` и `section.id` не являются обещанным Liquid-контрактом виджета. Fallback вроде `faq` даёт одинаковые ID при независимом рендере. Для собственного accordion назначай уникальный префикс экземпляра в JS до связывания контролов; при повторном mount сохраняй связи живых узлов либо переинициализируй их полностью. Не полагайся на случайное накопление Liquid assign между соседними виджетами.

## Режимы и редактор

Режим одного открытого ответа ограничивает только текущий корень. Если defaults открывают все ответы, single-режим нормализует начальное состояние до одного. Multi-режим позволяет открыть несколько, включая повторное закрытие каждого.

Передавай режим явно, например `data-faq-single="{{ widget_settings.accordion-mode }}"`, затем сравнивай со строкой `true`. Поиск подстроки в style зависит от форматирования CSS-переменных и хуже отражает контракт настройки. Делегированный click на корне позволяет добавить/переставить блок без повторного навешивания обработчиков на каждый вопрос. Повторный mount не должен умножать действия.

Блок без вопроса не создаёт пустой контрол; при отсутствии пригодных блоков не выводи пустой интерактивный список. Вопрос — экранированный текст; answer допускает HTML из предназначенного для этого поля. Сохраняй корректную вложенность заголовков, ссылок и управляющих элементов. Пустой заголовок секции не ломает переключение.

Проверь два экземпляра, initial single/multi, мышь/Enter/Space, ссылку в ответе, пустой вопрос, длинный текст, добавление/перестановку и замену разметки редактором. ID и настройки проверяются на настоящей странице с двумя экземплярами, а не только на fixture с заранее уникальными префиксами.
