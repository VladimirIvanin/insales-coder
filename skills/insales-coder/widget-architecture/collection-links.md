# Статическая сетка категорий

Выбирай этот пример для обычных ссылок на категории, названий, количества товаров и необязательных изображений. Клиентского поведения нет: `snippet.js`, jQuery и lazyload-библиотека не нужны. Изображения используют нативный `loading="lazy"`.

[Пакет](examples/collection-links/info.json): [Liquid](examples/collection-links/snippet.liquid), [SCSS](examples/collection-links/snippet.scss), [форма](examples/collection-links/settings_form.json), [defaults](examples/collection-links/settings_data.json), [сообщения](examples/collection-links/messages.json). Выбери собственный handle. Категория галереи `benefits` взята как пример карточек; её наличие в целевом каталоге проверяется отдельно. Пакет не использует классы `my-layout`, поэтому список `libraries` пуст.

Для этой статической композиции начни с шести файлов пакета: адаптируй handle, настройки и число колонок к запросу. Разделы runtime/common.js нужны при добавлении клиентского поведения; общий справочник Liquid — при изменении источников данных или фильтров.

## Данные и настройки

При пустом выборе показываются дочерние категории `collections.root_category`, при выбранном `parent-collection` — дочерние категории этого объекта. Поле типа `collection` выбирает handle для `collections[handle]`. Если выбранная категория отсутствует или не имеет дочерних разделов, выводится пустое состояние. Ссылки берутся из `category.url`, изображения — из `category.menu_image`, количество — из `category.products_count`.

Для `no_image` выводится исходный `large_url`, для настоящего изображения размер передаётся первым аргументом `image_url: 600`. Название рядом со снимком уже даёт имя ссылке, поэтому `alt` пустой. [Контракт menu_image](../liquid-collection-menu-image/reference.md).

Заголовок, подзаголовок, родительская категория, скрытие изображений, цвета и отступ редактируются. CSS читает цвета с fallback непосредственно в свойствах, не переопределяет входную переменную через неё же. Сетка задаёт ровно четыре колонки, до 767 px — две; меньшее число карточек не растягивает их на всю строку. Это выбранная композиция, которую можно адаптировать под задачу.

Сообщения и defaults содержат ru/en. Для русского количества учитываются окончания и исключения 11–14; для дополнительных языков адаптируй склонение. Кеш включает widget/collections/products: здесь выводятся и категории, и количества, а `menu_image` может зависеть от товара. [Зависимости кеша](../liquid-widget-cache-keys/reference.md).

При доступной витрине проверь пустой список, длинные названия, настоящую картинку/заглушку, количества 0/1/2/5/11/21/22, сохранение цвета и выбранной категории. Для точного числа колонок измерь сетку на нужных ширинах; минимальная ширина карточки сама по себе его не гарантирует. Два экземпляра имеют независимые настройки и не требуют клиентской инициализации.
