# Структурная проверка настроек поколения 4

Скрипт проверяет `settings_form.json` и, при наличии, `settings_data.json`. Нужен Node.js, внешние пакеты, MCP и доступ к магазину не требуются. Форма поколения 2/3 имеет другой контракт и этим скриптом не проверяется.

Задай `SKILL_DIR` по расположению прочитанного `SKILL.md`, `WIDGET_DIR` — каталог пакета. Команда работает из любого cwd; можно передать несколько каталогов:

```bash
node "$SKILL_DIR/scripts/validate-settings-form.mjs" "$WIDGET_DIR"
node "$SKILL_DIR/scripts/validate-settings-form.mjs" --json "$WIDGET_DIR"
```

## Ошибки и предупреждения

Ошибки: неверный JSON; корень формы не объект; отсутствие массивов `content`/`design` или дополнительные корневые вкладки; группа без массива `items`; поле не объект или без непустого строкового `type`; корень defaults не объект. Пустые вкладки/группы и отсутствие `settings_data.json` допустимы.

Предупреждения с точным путём поля:

- Нет `label` у именованного поля, кроме `info`, `current-page-description`, `link-to-widget`.
- Повторяется `name`, в том числе между вкладками.
- Начальное значение `text` содержит HTML-тег: в defaults, переводах, `default` или `value` поля; стоит рассмотреть `rich-text`.
- Числовой `min` больше `max`.

Предупреждение требует оценки контекста, а не автоматической замены. Неизвестные типы и свойства, произвольные локали, `null`, специальные объекты с `_type`, отсутствие defaults и дополнительные значения defaults не блокируются. Скрипт не определяет, используется ли настройка: её могут читать SCSS и механизмы платформы.

Коды выхода: `0` — структурных ошибок нет, предупреждения возможны; `1` — ошибки в содержимом; `2` — неверные аргументы или ошибка чтения. При `2` проверка входов не завершена. Режим `--json` возвращает `results` по каталогам; каждый содержит `errors`/`warnings` с `code`, `file`, `path`, `message`. Node API: `validateSettings({ formSource, dataSource })`, где входы — строки JSON, а `dataSource` необязателен.

## Границы

Это проверка структуры, без списка всех типов редактора и без исполнения Liquid/JS/SCSS. Она не подтверждает доступность selector, правильность `messages`, координаты, маршруты ссылок или применение цвета на витрине. Изменение настройки проверь по её потребителю и, при доступном редакторе, сохранением и повторным открытием. [Типы и использование настроек](settings-reference.md).
