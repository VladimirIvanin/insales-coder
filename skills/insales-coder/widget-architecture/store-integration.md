# Установка через MCP

Это дополнительный способ установки и проверки. Перед изменением существующего виджета прочитай актуальный код магазина. Для больших исходников настрой абсолютный `INSALES_MCP_WIDGET_SOURCE_ROOT` и передавай относительные пути в `source_files`, включая повторы после конфликта ревизии. Сверь SHA-256 черновика с локальными файлами; после `apply_change` прочитай сохранённый код и сравни его. Если чтение ещё показывает старую версию, повтори после короткой задержки.

Для изображений используй доступный `propose_theme_image_upload(destination=account_file)` и затем `apply_change`; проверь привязку через чтение темы. Ошибка разрешённого каталога загрузки и способы её исправления — в [editable-theme.md](editable-theme.md). MCP-сохранение или аудит состава секций не заменяют проверку поведения.
