# Иконки редактора (icon_group / button-group)

Используются в `settings_form.json` в поле `icon` у опций типа `icon_group`. Значение — строка **с префиксом `mdi-`**, как в визуальном редакторе (класс в разметке: `class="icon mdi-text-align-left"`).

## Пример в settings_form.json

```json
{
  "name": "align-title",
  "type": "icon_group",
  "options": [
    { "value": "left", "title": "{{ messages.left }}", "icon": "mdi-text-align-left" },
    { "value": "center", "title": "{{ messages.center }}", "icon": "mdi-text-align-center" },
    { "value": "right", "title": "{{ messages.right }}", "icon": "mdi-text-align-right" }
  ]
}
```
