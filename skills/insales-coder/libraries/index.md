# Библиотеки виджетов: выбор нужного справочника

Открывай этот индекс, когда меняешь `libraries` в `info.json` или используешь API подключённой библиотеки. Затем читай только раздел нужной задачи. `libraries` — массив **handle** из каталога `WidgetLibrary`; это не имена npm-пакетов. Скрипты и стили подключает платформа. Не добавляй вручную `<script>` или `<link>` в `snippet.liquid`.

Снимок локального каталога от 25.09.2026. Если доступен магазин, перед добавлением handle проверь актуальный `read_theme_catalog(kind=libraries)`: API возвращает только опубликованные библиотеки, а также их текущие `js_file_url` и `css_file_url`. Не сохраняй эти адреса в скилле — они могут измениться. Валидатор `info.json` проверяет формат массива, но не существование handle. Указывай каждую непосредственно используемую зависимость у своего виджета: старые виджеты иногда работают за счёт библиотек соседних секций страницы.

**Примеры:** в справочниках ниже сохранены короткие, адаптированные паттерны системных виджетов. `info.json` показывает нужный фрагмент массива; остальные обязательные поля типа виджета описаны в [архитектуре](../widget-architecture/reference.md). Код предполагает стандартные `widget` и `$widget` в `snippet.js`. Примеры не являются доказательством, что библиотека доступна на любой странице без объявления в своём виджете.

**Выбор источника:** каталог магазина определяет допустимые handle и URL; содержимое подключаемого файла — доступный API; официальная документация соответствующей версии объясняет поведение; системные виджеты показывают принятые способы применения. Не переносить API из более новой версии без проверки подключаемого файла.
