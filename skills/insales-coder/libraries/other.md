# Библиотеки без паттернов в системных виджетах

Ниже — записи каталога, для которых в исследованных системных виджетах нет примеров. Это краткий указатель, а не подтверждённый InSales-рецепт. Перед использованием проверь публикацию в каталоге магазина и API **подключаемой версии**; актуальная документация проекта может описывать более новый выпуск.

| Handle | Что подключает и глобальный API | Статус и источник |
|---|---|---|
| `gsap3` | JS 3.12.5, `gsap` для анимаций; CSS нет | Опубликована. [Документация GSAP 3](https://gsap.com/docs/v3/GSAP/) |
| `swiper` | JS + CSS 6.3.5, `Swiper` для слайдеров | Опубликована. [Документация API](https://swiperjs.com/swiper-api/) |
| `sweetalert2` | JS + CSS 11.0.16, `Swal` для диалогов | Опубликована. [Документация](https://sweetalert2.github.io/) |
| `tingle` | JS + CSS 0.16.0, `tingle` для модальных окон | Опубликована. [Документация](https://robinparisi.github.io/tingle/) |
| `splide-auto-scroll` | JS 0.5.3, расширение `window.splide.Extensions.AutoScroll`; CSS нет | **Не опубликована**. [Документация расширения](https://splidejs.com/v3/extensions/auto-scroll/) |
| `lodash` | JS-файл 4.17.21 (запись `lodash@4.17`), глобальный `_`; CSS нет | **Не опубликована**. [Документация API](https://lodash.com/docs/4.17.15) |

Не считай `lodash` доступным только потому, что старый код использует `_`: его подключение может зависеть от других ресурсов страницы. Для нового виджета с неопубликованной библиотекой выбирай опубликованную альтернативу или уточняй доступность в каталоге магазина.
