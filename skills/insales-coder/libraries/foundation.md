# Базовые зависимости

## `my-layout` — CSS и поведение страницы

Подключает `core-css.css` и `my-layout.js`; это не JS-конструктор виджета. CSS даёт `.layout`, `.layout__content`, сетки, отступы и переменные оформления. Скрипт после загрузки страницы выставляет `--vh`, размеры фиксированных панелей и `settings_loaded`. В системных виджетах handle встречается часто, но не у каждого типа: указывай его, когда используешь эти стили или поведение, а не автоматически ради любого JS.

Для классов, SCSS-миксинов и CSS-переменных читай [справочник Core CSS](../widget-architecture/core-css-reference.md). API и состав CSS/JS проверены по подключаемым файлам на дату исследования; актуальные адреса смотри в каталоге магазина.

## `jquery` — работа с DOM

Подключает jQuery 3.5.1 и даёт глобальные `$`/`jQuery`. `snippet.js` обычно уже получает `$widget` как jQuery-коллекцию, но виджет, использующий `$`, `.find()`, `.on()` или `.each()`, должен объявлять `jquery` сам. Для нескольких экземпляров используй `$widget.each((_, el) => { … })`, а селекторы внутри ограничивай `el`. Источник API: [официальная документация jQuery](https://api.jquery.com/); подключаемую версию проверяй в каталоге магазина.

## `commonjs_v2` — API витрины InSales

Предоставляет `Cart`, `Products`, `EventBus`, `FavoritesProducts`, `Compare` и другие сервисы витрины; сам по себе не заменяет явный `jquery`, когда код использует `$`. Для методов, событий, разметки и рабочих примеров читай [справочник common.js](../commonjs-widget/reference.md), затем только нужный подраздел. Источник API: [документация common.js](https://docs.liquidhub.ru/common.v2.js/); подключаемый файл проверяй в каталоге магазина.
